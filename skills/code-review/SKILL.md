## コードレビュー

対象: $ARGUMENTS

[checklist.md](checklist.md) のチェックリストに従い、以下の手順でレビューを実施せよ。

### 手順

1. 変更差分を取得して全体像を把握する
2. 変更されたファイルをすべて読む
3. チェックリストの各観点で問題を検出する
4. 重大度別に分類して報告する

### 出力フォーマット

以下の形式で報告せよ：

#### 概要
変更内容の1-2行の要約

#### 指摘事項

各指摘を以下の形式で記載：

- **[重大度]** `ファイル名:行番号` — 指摘内容
  - 理由と改善案

重大度レベル：
- 🔴 **MUST** — マージ前に修正必須（バグ、セキュリティ、データ損失）
- 🟡 **SHOULD** — 強く推奨（設計問題、可読性の大幅な低下）
- 🔵 **NIT** — 任意（命名、スタイル、軽微な改善）

#### 良い点
変更の中で良いと思った点があれば記載
